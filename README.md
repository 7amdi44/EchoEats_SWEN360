# EchoEats – Dynamic Pricing Food Waste Marketplace

EchoEats is a surplus-food marketplace. Food businesses publish available surplus items with expiry information and a vendor-defined pricing strategy. Consumers can discover nearby offers, reserve items, complete a simulated payment, and collect orders using a pickup code.
