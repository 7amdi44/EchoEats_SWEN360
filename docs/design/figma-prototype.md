# EchoEats Mobile Wireframes and Prototype

**Figma file:** [EchoEats – Mobile Wireframes & Prototype](https://www.figma.com/design/fFSiqMCP6gIAlvUgoSJA8d)

The Figma file contains eight customer screens and five vendor screens, designed as mobile frames. It includes a customer navigation flow and a vendor navigation flow.

## Customer screens

1. Login
2. Account creation
3. Nearby deals
4. Filters
5. Product details
6. 15-minute reservation hold
7. Pickup code after payment
8. Order history

## Vendor screens

1. Vendor listings dashboard
2. Post food
3. Pickups
4. Notifications
5. Business profile

## Prototype scope

The prototype demonstrates screen navigation and selected visual interactions. It does not execute the actual EchoEats application logic, process a payment, change inventory, or run a live reservation countdown.
