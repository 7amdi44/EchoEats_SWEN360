# User Stories (Sprint 1)

Selected at Sprint Planning on October 4th, 2026.

| # | User story |
| --- | --- |
| 1 | As a consumer, I want to create an account with my email and password. |
| 2 | As a consumer, I would like to see a list of available items and filter by dietary tag, price and distance, so that I can quickly find something suitable. |
| 3 | As a consumer, I want to see an item's current price update on screen without refreshing, so that I always know what I would pay. |
| 4 | As a consumer, I want to reserve an item and have it held for 15 minutes, so that it is not sold to someone else while I complete payment. |
